# 발표모드 개발 계획

| Phase | 내용 | 상태 |
|---|---|---|
| 1 | 기존 집중모드 분석: 집중모드=사이드바/헤더 숨김뿐. PdfCanvas(연속 스크롤, RenderService 캐시, HiDPI) 재사용 결정 | 완료 |
| 2 | 전체화면 PresentationWindow, 전체 페이지/너비 맞춤, 단축키, 진입 버튼 | 완료 |
| 3 | 구간 이동(50/75/90), 경계 처리, 부드러운 스크롤, 마우스 지점 확대 | 완료 |
| 4 | 두 PDF: 동기화/기준점, 한쪽 집중, 전환 | 완료 |
| 5 | 레이저, 형광펜, 클릭 확대, 검은 화면, 플로팅 도구 모음 | 완료 |
| 6 | 모니터 선택/분리 대응, HiDPI·메모리 상한(max_zoom_for) | 코드 완료, 실장비 미검증 |
| 7 | 테스트·Opus 리뷰 | 진행/완료는 PROGRESS 참조 |

설계 결정: 작업 화면 상태 보존을 위해 발표 창은 별도 캔버스를 사용. PdfCanvas는 margin/page_gap/bg_color/probe_ratio를 인스턴스 속성화(기본값 동일)하여 서브클래스.
