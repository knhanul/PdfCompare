# 발표모드 사양 (Presentation Mode)

기존 '집중모드'(사이드바 숨김)를 PDF 보기 / 두 PDF 동시보기에서는 **발표모드**로 대체한다.
다른 도구(비교·편집·폼 등)의 집중모드(사이드바 숨김)는 그대로 유지한다.

## 진입/종료
- 진입: 헤더 '발표모드' 버튼(뷰어/동시보기 화면에서만 라벨 변경), 도구 줄 '▶ 발표모드', 명령 팔레트, **F5**(현재 페이지부터) / **Shift+F5**(처음부터)
- 종료: Esc, 도구 모음 '종료 ✕'. 작업 화면 캔버스는 발표 중 변경되지 않는다(발표 창이 별도 PresentationCanvas 사용).

## 보기 방식
| 모드 | 맞춤 | Space/PageDown | 휠 |
|---|---|---|---|
| 전체 페이지 | 페이지 맞춤·가운데 | 다음 페이지 | 페이지 넘김 |
| 화면 너비 맞춤 | 너비 맞춤 | 다음 구간(기본 75%) | 자유 스크롤 |
| 구간별 넘기기 | 너비 맞춤 | 다음 구간 | 노치당 한 구간 |
| 부드러운 스크롤 | 너비 맞춤 | 다음 구간 | 애니메이션 스크롤, 자동 스크롤(A) |

추천: 가로형→전체 페이지, 세로형→너비 맞춤+75%, 혼합→다수결 + 페이지별 자동 맞춤(사용자가 모드를 직접 고르면 자동 맞춤 해제).
구간 이동량 = 뷰포트 높이 × (50/75/90%). 마지막 구간은 페이지 하단에 정확히 정렬(누락 없음), 끝에서 다음 페이지 처음, 처음에서 이전 페이지 마지막 구간.

## 키
F5/Shift+F5 · Esc · Space/PageDown/Shift+Space/PageUp · ←/→ 페이지 · ↑/↓ 소이동(Ctrl: 크게) · Home/End 페이지 맨 위/아래 · +/−/Ctrl+휠 확대(마우스 지점 고정) · Ctrl+0 맞춤 복귀 · B(또는 .) 검은 화면 · L 레이저 · P 형광펜 · Z 클릭 확대 · C/Shift+C 형광펜 지우기 · A 자동 스크롤 · Tab 도구 모음 · Y 동기화(두 PDF)

## 두 PDF
- 좌우 동일 / 왼쪽 집중(75:25) / 오른쪽 집중 / 집중 전환 / 보조 숨김
- 각 PDF 독립 페이지·확대율. 스크롤 동기화: off / normal(같은 위치) / anchor(기준점, `scroll_anchor` 재사용)
- 동기화 해제 → 독립 이동 → '⌖ 위치 맞춤' → 재개. 해제 후 재개 시 위치가 어긋나 있으면 점프 없이 보류(stale)

## 도구
레이저(오버레이, PDF 비수정) · 형광펜(문서 좌표 pt 저장, 세션 한정) · 클릭 확대(재클릭 복귀) · 검은 화면(첫 해제 입력은 소비) · 자동 hide 하단 플로팅 도구 모음

## 모니터
기본: 호출 창이 있는 모니터. 설정 ⚙ → 발표 모니터에서 변경. 대상 모니터 분리 시 기본 모니터로 이동.
